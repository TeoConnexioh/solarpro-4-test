# Lumina Run — 빛의 숲을 끝없이 달려

Solar Pro 4의 역량을 한 장면으로 보여주는 HTML5 인피니트 파쿠르 게임.

백엔드 없이, **하나의 정적 HTML 파일(`index.html`)**이 다음을 동시에 품고 있습니다:

- **WebGL/GLSL 배경 셰이더** — 보랏빛 하늘, 태양 글로우, 먼 산 실루엣, 하단 안개, 미세한 바람 결까지 프래그먼트 셰이더로 실시간 렌더링
- **Procedural 지형** — Perlin/Simplex-style noise 기반 지형이 매 러닝마다 다르게 생성되고, 동일 시드로 재현 가능
- **2D 파티클 시스템** — 착지 먼지, 달리기 트레일, 수집 반짝임, 바운스 파편이 풀 기반으로 실시간 동작
- **절차적 오디오** — Web Audio API 신스 발소리(속도 따라 피치 상승), 수집 차임, 배경 패드, 추락 사운드

---

## 바로 해보기

1. 이 레포를 클론하거나 `index.html`을 다운로드
2. 최신 브라우저에서 직접 열기 (file:// 또는 로컬 서버)
3. **공간바 / 위 화살표 / W / 터치 탭**으로 시작 → 점프
4. **← → / A D / 좌우 스와이프**로 이동

**조작 디테일:**
- 변수 점프: 탭/공간바를 길게 누르면 더 높이 뜀 (공중에서도 초기 구간 짧게 추가 상승)
- 터치: 탭 = 점프(길게 = 높게), 좌우 스와이프 = 이동

---

## 게임 특징

- 밝은 판타지/자연 톤 — 연한 하늘~라벤더 하늘, 초록/이끼 계열 지형, 빛나는 마법 씨앗 수집물
- 매 러닝이 다른 세계 — 시작 화면의 seed 숫자로 그 지형이 결정됨
- 시드 공유: 같은 seed로 친구랑 같은 지형에서 뛸 수 있음
- 로컬 기록(localStorage): 최고 거리+수집 합산 점수 저장. 서버 랭킹 없음(백엔드 없음)
- 모바일 대응: 터치 입력 + 반응형 캔버스

## 빌드·변경 없음

의존성 없음. `index.html` 하나만 있으면 됩니다.

```
open index.html
# 또는
python3 -m http.server 8080
# → http://localhost:8080/index.html
```

## 시드 공유 URL 예시

```
index.html?seed=12345
```

(선택 구현: seed 쿼리 파라미터를 읽어서 시작 시드로 사용)
