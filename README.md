# Lumina Run — 빛의 숲을 끝없이 달려

떠 있는 섬 사이를 끝없이 뛰어 넘는 판타지 파쿠르. **`index.html` 파일 하나**가 전부이고, 빌드도 의존성도 백엔드도 없습니다.

하나의 정적 HTML 안에 이것들이 함께 돌아갑니다:

- **WebGL/GLSL 배경 셰이더** — 라벤더 하늘, 태양 원반과 이중 글로우, fbm 노이즈로 만든 먼 산 3겹, 흐르는 구름 띠, 수평선 안개까지 프래그먼트 셰이더에서 실시간 생성 (WebGL이 없으면 2D 그라데이션 하늘로 자동 폴백)
- **Procedural 지형** — 시드 기반 난수(Mulberry32)로 떠 있는 섬·틈·가시덤불·공중 발판·씨앗을 무한 생성. 같은 시드는 어떤 기기에서든 같은 세계
- **2D 파티클** — 착지 먼지, 도약 반짝임, 수집 폭발, 추락 파편
- **절차적 오디오** — Web Audio 신스로 발소리(속도 따라 피치 상승), 착지·수집 차임(5음 음계), 8초마다 화음이 도는 배경 패드, 추락 사운드

## 설계에서 지킨 것

**공정하게 어려운.** 지형은 무작위지만 아무렇게나 만들지 않습니다. 생성기가 그 지점의 속도로 실제 점프 포물선을 계산해서

- 틈은 도달 거리에서 *일찍 뛰는 여유(34px) + 착지 여유(26px) + 가시 폭*을 뺀 값의 74% 안쪽
- 오르막은 점프 정점(124px) 안쪽에서만, 그것도 속도에 비례해 완만하게
- 발판 길이는 **끝까지 누른 최대 점프**도 그 발판 안에 떨어지도록 보장 (뛰어넘어 지나치는 죽음 없음)
- 가시덤불은 틈 건너편 입구에만 — 틈과 함께 한 번의 점프로 넘습니다. 공중에서 손쓸 수 없는 죽음을 만들지 않기 위해

시드 80개 × 섬 260개(도약 2만여 회)를 궤적으로 검증해 **도달 불가 구간 0개**를 확인했습니다.

**관용적인 조작.** 코요테 타임(발판을 떠난 뒤 7프레임까지 점프 허용), 점프 버퍼(착지 8프레임 전 입력 기억), 모서리 걸치기(아슬아슬하게 닿으면 끌어올림), 스윕 충돌 판정(빠른 낙하에도 바닥을 관통하지 않음).

**어느 화면에서든 같은 세계.** 물리는 60Hz 고정 스텝이라 120Hz 화면에서도 속도가 같고, 좁은 화면에서는 뷰를 축소해 다음 섬이 보이도록 하되 월드 자체는 건드리지 않습니다.

**접근성.** `prefers-reduced-motion`을 존중해 화면 흔들림·섬광·파티클을 줄이고, HUD는 밝은 하늘 위에서도 읽히도록 자체 배경을 가지며, 런 결과는 `aria-live`로 안내합니다.

## 시드 공유

```
index.html?seed=20260814
```

결과 화면의 **시드 링크 복사**가 현재 세계의 URL을 클립보드에 넣어 줍니다. 기록은 `localStorage`에만 남습니다(서버 랭킹 없음).
